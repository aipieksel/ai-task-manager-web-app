# Security policy

## Reporting a vulnerability

Please use GitHub’s private vulnerability-reporting feature for this repository. Do not open a public issue containing exploit details, credentials, private filesystem paths, or user task data.

Include affected versions, reproduction steps, impact, and any suggested mitigation. Maintainers will acknowledge a valid report as soon as practical and coordinate disclosure after a fix is available.

## Supported versions

Security fixes target the latest release and the default branch. This local-first application should still be treated as privileged software because its runtime can read and update project folders explicitly connected by the user.
