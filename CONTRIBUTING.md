# Contributing

Thank you for helping improve Agentic AI Projects Task Manager.

1. Open an issue for substantial behavior, data-contract, or architecture changes.
2. Create a focused branch and keep private task data, credentials, recordings, generated output, and machine-specific paths out of commits.
3. Update the relevant documentation and tests with the implementation.
4. Run `npm test` and include the exact result in the pull request.
5. For UI changes, verify source and built views at desktop and mobile sizes with no console or network errors.

Pull requests should explain the problem, chosen approach, compatibility impact, verification performed, and any remaining limitations. Contributions are accepted under the repository’s Apache-2.0 license.
